# 一个按键多种效果：上下文感知的按键系统

## 核心原理

**按键本身不做任何事，按键只是触发"查找当前上下文中最优先的动作"这一逻辑。**

玩家按 E → 扫周围 → 按优先级/距离决定干什么 → 执行。

---

## 常见做法：优先级检测链

```
按 E →
  检测周围有没有"可交互"物体（门、NPC）
    有 → 执行交互（优先级最高）
    没有 →
  检测脚下有没有可拾取物品
    有 → 执行拾取
    没有 →
  检测手上武器状态
    空了 → 换弹
    满了 → 切装备
```

代码大概长这样：

```csharp
void OnPressE()
{
    // 按优先级从高到低检测
    if (TryInteract()) return;      // 1. 交互（门、NPC）
    if (TryPickup()) return;        // 2. 拾取
    if (TryReload()) return;        // 3. 换弹
    if (TrySwitchWeapon()) return;  // 4. 切装备
}
```

每个 `TryXxx` 方法负责检测自己的条件是否满足，满足就执行并返回 `true`（阻断后续检测），不满足就返回 `false`（继续往下）。

---

## 本项目已有的实现

`Player.TryInteract()` 就是**用 `OverlapCircleAll` 扫描周围物体 → 找实现了 `IInteractable` 接口的 → 找最近的**：

```csharp
// Player.cs:176-199
private void TryInteract()
{
    Transform closest = null;
    float closestDistance = Mathf.Infinity;
    Collider2D[] objectAround = Physics2D.OverlapCircleAll(transform.position, 1.5f);

    foreach (var target in objectAround)
    {
        IInteractable interactable = target.GetComponent<IInteractable>();
        if (interactable == null) continue;

        float distance = Vector2.Distance(transform.position, target.transform.position);
        if (distance < closestDistance)
        {
            closestDistance = distance;
            closest = target.transform;
        }
    }

    if (closest == null) return;
    closest.GetComponent<IInteractable>().Interact();
}
```

**谁离玩家最近，E 键就是谁的。** 这是解决"同时能交互又能捡东西"的标准做法——距离排序选最近的。

---

## 扩展为多优先级检测

```csharp
private void OnPressE()
{
    // 优先级1: 近距离交互（门、NPC）—— 小半径
    if (TryInteract(radius: 1.5f, layer: interactionLayer)) return;

    // 优先级2: 捡起物品 —— 大一点的半径
    if (TryPickupItem(radius: 2f)) return;

    // 优先级3: 武器操作
    if (TryReloadOrSwitch()) return;
}
```

## 提示 UI：告诉玩家当前按键会触发什么

业界标准做法是提示文字随上下文实时变化：

- 检测到可交互物体 → 显示"按 E 交谈" / "按 E 开门"
- 检测到可拾取物品 → 显示"按 E 捡起 [物品名]"
- 什么都没检测到 → 什么都不提示（或者显示武器状态）

**提示不是按键变了，而是告诉玩家当前上下文里这个键会做什么。**

本项目中 `interactToolTip.SetActive(true)` 那个浮动提示就是这个模式的雏形。

---

## 如果上下文冲突怎么办？

用距离排序选最近的。项目 `Player.TryInteract()` 已经做了——遍历所有符合条件的目标，取距离最小的那个触发。美术再配合做个"当前选中物体高亮"（比如物品轮廓发光），体验就完整了。

---

## 总结

一个按键多种效果的本质不是"动态改按键绑定"，而是：
> **按 E → 扫描周围 → 按优先级/距离决定干什么 → 执行并阻断后续检测**

本项目 `IInteractable` + `TryInteract` 已经是这个模式的雏形，扩展只需要在检测链上多加几层。
